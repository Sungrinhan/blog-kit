# 발행 조건은 내용 해시에 묶인 발행 증거로 판정한다

블로그 레포에서 글을 공개(`draft: false`)하려면, 같은 내용 해시에 묶인 발행 게이트 결과·검수·학습 확인·사람 승인이 발행 증거 파일에 모두 있어야 한다. 업스트림의 전달 게이트 통과와 리뷰 nonce는 발행 조건으로 쓰지 않는다. nonce 상태는 기기 홈과 초안 절대 경로에 묶여 있어 다른 기기나 Cloudflare 빌드에서 검증할 수 없고, 전달 게이트는 이 블로그가 쓰지 않는 산출물(대표 이미지, PDF, 스크린샷, 영어 기준 점수)을 요구한다. 배포 빌드는 엔진 없이 블로그 레포에 둔 검증기 사본으로 돌고, 배포 명령 자체가 깨끗한 빌드와 검증 성공 뒤에만 업로드하도록 묶여 있다. 빌드가 실패했을 때 배포가 멈추는지는 Cloudflare 문서에 나와 있지 않기 때문이다.

## Considered Options

- 업스트림 전달 게이트(strict) 통과를 발행 조건으로 의무화: 대표 이미지를 기본으로 넣지 않는 결정(G16)과 P0 중심 검수 기준에 맞지 않아 기각.
- 승인 기록에 서명(기기 밖 비밀키, 서명 커밋): 두 기기의 키 관리 부담 때문에 기각. 같은 사용자 권한으로 도는 AI가 증거 파일을 위조하는 경우는 막지 않는 알려진 한계로 둔다.
- 빌드 뒤 증명 파일을 만들어 배포 직전에 대조: 배포 명령 안에서 빌드하는 것보다 형식만 하나 늘어 기각.

## Consequences

- 엔진을 업데이트해도 과거 증거는 증거에 적힌 계약 버전으로 판정하므로 이미 발행한 글이 깨지지 않는다. 지원하지 않는 계약 버전은 차단한다.
- 사이트 코드와 외부 자산의 변경은 내용 해시 범위 밖이다.
